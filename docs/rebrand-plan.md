## Phase 1B — Profile Fields for Professional Networking

### Database Migration

File: `supabase/migrations/0011_add_professional_profile_fields.sql`

```sql
ALTER TABLE profiles
  ADD COLUMN IF NOT EXISTS headline TEXT,
  ADD COLUMN IF NOT EXISTS expertise_areas TEXT[] DEFAULT '{}',
  ADD COLUMN IF NOT EXISTS certifications TEXT[] DEFAULT '{}',
  ADD COLUMN IF NOT EXISTS years_of_experience INTEGER,
  ADD COLUMN IF NOT EXISTS available_for_consulting BOOLEAN DEFAULT FALSE;
```

### TypeScript Types

**`src/types/index.ts`** — Add to `Profile`:
```ts
headline?: string | null
expertise_areas?: string[] | null
certifications?: string[] | null
years_of_experience?: number | null
available_for_consulting?: boolean | null
```

**`src/types/supabase.ts`** — Update `Database['public']['Tables']['profiles']['Row']` with same fields.

**`src/lib/validation.ts`** — Add Zod schema for new fields:
```ts
export const profileProfessionalSchema = z.object({
  headline: z.string().max(150).optional(),
  expertise_areas: z.array(z.string()).max(10).optional(),
  certifications: z.array(z.string()).max(10).optional(),
  years_of_experience: z.number().int().min(0).max(70).optional(),
  available_for_consulting: z.boolean().optional(),
})
```

### Edit Profile Page

**`src/app/[locale]/(dashboard)/profile/edit/page.tsx`** — Add form sections:
- **Professional Headline**: single-line text input (max 150 chars)
- **Expertise Areas**: multi-select tag input with predefined options:
  - Carbon Markets, Renewable Energy, ESG Reporting, Climate Policy,
    Biodiversity, Social Impact, Corporate Governance, Sustainable Finance,
    Energy Efficiency, Water Management, Circular Economy, Supply Chain
- **Certifications**: multi-select tag input with predefined options:
  - GRI Certified, SASB FSA Credential, CFA Certificate in ESG Investing,
    ISSP Sustainability Professional, TRUE Advisor, LEED AP, BREEAM Assessor,
    ISO 14001 Lead Auditor, CDP Accredited Provider
- **Years of Experience**: number input (0-70)
- **Available for Consulting**: toggle

### Public Profile Page

**`src/app/[locale]/(public)/u/[username]/page.tsx`** — Display new fields:
- Headline below display name (styled like LinkedIn headline)
- Expertise areas as badges/tags
- Certifications as badges/tags
- Years of experience as stat
- "Available for consulting" badge

### Onboarding Form

**`src/components/onboarding/OnboardingForm.tsx`** — Add to Step 2:
